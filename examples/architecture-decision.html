How should we deliver customer webhooks?

We need durable delivery, tenant isolation, and replay without making the request path depend on customer endpoints.

OptionFailure isolationOperationsTradeoff
Direct from APIA slow customer endpoint consumes request capacity.Few moving parts.Lowest setup cost, weakest reliability.
Shared durable queueRetries leave the request path, but a noisy tenant can dominate workers.One queue and one worker pool.Good default if fairness controls are explicit.
Queue per tenantStrong isolation and independent replay.High queue cardinality and lifecycle overhead.Best isolation, highest operational cost.

Recommendation

Use a shared durable queue partitioned by tenant, with per-tenant concurrency and retry budgets. Store immutable delivery attempts for 14 days so support can replay safely.

Open decision: should replay preserve the original signing secret or use the tenant’s current secret?
