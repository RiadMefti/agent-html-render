Migration plan · Draft for review

Move sessions from memory to durable storage

Remove single-instance affinity without forcing a flag-day cutover or invalidating active sessions.

  1. Define the storage contract

    Freeze serialization, TTL, and conflict behavior behind the existing session interface.

    Gate: compatibility fixtures pass against both stores.

  2. Shadow and compare

    Write to both stores while reads remain in memory. Compare sampled records without logging session content.

    Gate: mismatch rate stays below 0.01% for seven days.

  3. Switch reads by cohort

    Move internal tenants first, then 5%, 25%, and 100%. Keep dual writes during the ramp.

    Rollback: restore memory reads without data conversion.

  4. Retire memory authority

    Stop dual writes after the longest session TTL and remove affinity from the load balancer.

    Gate: replay and regional failover drills pass.
